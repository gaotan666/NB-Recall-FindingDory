# Third-party source

`vendor/findingdory-habitat/` is the source snapshot used by the historical submission2 experiment, including local simulator/evaluation adaptations. The upstream revision recorded with that snapshot is in `environment/vendor_revision.txt`.

Nested Habitat source and its existing LICENSE files are preserved. Third-party code remains subject to its respective original licenses; this repository does not relicense it. Large media, datasets, environments, weights and Git metadata are excluded from the source snapshot distributed here.

The model and datasets must be obtained and used under their original terms. Repository access does not transfer ownership or provide access to the experimental server.
